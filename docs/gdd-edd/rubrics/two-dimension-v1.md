# GDD 两维度评分标尺 v1

## 评价维度

1. 核心玩法：判断核心循环、有效选择与反馈、规则和数值一致性、设计可执行性是否支撑目标体验。
2. 玩家体验：判断目标与反馈、上手和信息清晰度、UI 与视觉设计明确度、节奏与重复度、预期体验表现是否支撑目标玩家。

上述内容是取证检查项，不是二级评分项，不得分别打分。每个维度只给一个 `0-50` 总分。

## 统一分档

| 分数 | 客观定义 |
| --- | --- |
| 0-15 | 关键设计缺失或相互冲突，直接破坏该维度的目标体验。 |
| 16-25 | 基本设计成立，但存在明确且显著的体验问题。 |
| 26-35 | 达到基本设计目标，存在不破坏核心体验的可迭代缺口。 |
| 36-45 | 设计清晰完整、基本可验证，并形成可定位的体验亮点。 |
| 46-50 | 接近标杆，证据充分，几乎没有明显缺口；应极少使用。 |

评分必须同时给出客观观察、GDD 证据和理由。证据不足必须单独列明，不得用推测补齐。
