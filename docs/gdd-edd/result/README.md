# 评价模板与结果

## 当前模板

当前生效模板是 `评价模板-v7.md`：

- 体验价值 30 分、玩法与系统 40 分、内容与呈现 30 分。
- AI 根据 `rubrics/three-dimension-v2.md` 每维直接给一个总分，不创建二级评分。
- 人工通过现有玩家 Web 每维给 `1-5` 分。
- 每维 AI 占 70%、人工占 30%，三个维度按 30%、40%、30% 计入总分。
- 模板只负责 Result 的呈现结构，由 Node 填充；AI 不读取、创建或改写模板。

## 新结果

每次 `npm run eval` 都会创建一份新的 Result，并与同标识的 Progression、Problem 互相引用。Result 保存：

- AI 三维度分数和 AI 总分；
- 客观观察、证据、评分理由和证据不足项；
- 问题数量及 Problem 链接；
- 人工评分样本、分布、均分；
- AI 与人工合并后的三维度分数和最终总分。

玩家 Web 只维护当前会话的标记区块和顶部数值字段，不改写 AI 证据或问题内容。

完整问题和最小建议只保存在 Problem，避免 Result 重复。历史 run2 文档保留其原始内容；新职责从后续运行生效。
